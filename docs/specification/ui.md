# JSPaint UI 仕様書

本ドキュメントは JSPaint の UI 設計、コンポーネント構成、カラースキーム、操作系およびパラメータ仕様を管理・記録する仕様書です。

---

## 1. デザインコンセプト & スタイルガイド
*   **デザイン方針**: Photoshop / Figma ライクなプロフェッショナル・高密度ダークテーマ
*   **カラースキーム**:
    *   Base Background: `#0a0a0a` (neutral-950)
    *   Panel / Header / Footer: `#171717` (neutral-900)
    *   Border / Divider: `#262626` (neutral-800)
    *   Accent / Primary: `#2563eb` (blue-600) 〜 `#4f46e5` (indigo-600)
    *   Filter / Effect Accent: `#9333ea` (purple-600)
    *   Canvas Background: 市松模様（チェッカーボード: `#1e1e1e` / `#2a2a2a`）
*   **タイポグラフィ**: Inter (欧文・UI全般), JetBrains Mono (座標・数値・バージョン表記)

---

### 2.1 Header (Top Bar)
*   **配置**: 画面最上部 (高さ: 48px / `h-12`)
*   **要素**:
    *   ロゴ・タイトル (`JSPaint [Inpainting]`)
    *   **画像入出力ボタン群** (詳細は「2.6 画像入出力とホストモード」参照):
        *   開く (`FolderOpen` — ドラッグ&ドロップ / Ctrl+V でも読み込み可) **[standalone のみ]**
        *   保存 (`Save` — 合成画像を PNG 保存, `Ctrl+S`) **[standalone のみ]**
        *   クリップボードコピー (`ClipboardCopy` — 合成画像をコピー, `Ctrl+Shift+C`) **[両モード]**
    *   Undo / Redo ボタン (ショートカット: Ctrl+Z / Ctrl+Y)
    *   ズームコントロール (Zoom In, Zoom Out, 拡大倍率%・100%リセット, 画面フィット)
    *   ドキュメント情報 (ファイル名, **実寸 (可変)**, ステータス)
    *   「キャンセル」ボタン (編集リセット)
    *   「完了 (Export)」ボタン (Inpaintingエクスポートモーダル表示)

### 2.2 Toolbox (Left Bar)
*   **配置**: 画面左側 (幅: 56px / `w-14`)
*   **ツール一覧**:
    *   **描画**:
        *   ブラシツール (`Paintbrush`, ショートカット: `B`)
        *   消しゴムツール (`Eraser`, ショートカット: `E`)
        *   べた塗り / バケツツール (`PaintBucket`, ショートカット: `G`)
    *   **図形**:
        *   直線ツール (`Minus`, ショートカット: `L`)
        *   矩形ツール (`Square`, ショートカット: `U`)
        *   円ツール (`Circle`, ショートカット: `O`)
    *   **選択 (Inpainting範囲)**:
        *   矩形選択 (`BoxSelect`, ショートカット: `M`)
        *   投げ縄選択 (`Lasso`, ショートカット: `Q`)
        *   多角形ポリゴン選択 (`Pentagon`, ショートカット: `P`)
        *   自動選択 / 魔法の杖 (`Wand2`, ショートカット: `W`)
        *   選択ペン (`Pencil`, ショートカット: `K`) — ブラシのようにドラッグしてマスクを直接描画。不透明度はブラシと共用 (サイズはツール別に記憶)
    *   **レタッチ**:
        *   指先ツール (`Smudge`, ショートカット: `S`) — ドラッグで色をにじませる
        *   覆い焼き / 焼き込み (`Sun` / `Moon`, ショートカット: `D` / `J`, 階層ボタン) — ドラッグで明るく/暗く
        *   膨張ブラシ (`Expand`, ショートカット: `V`) — ブラシ中心を基準にピクセルを放射状に押し広げるリキフィ系ツール (逆マッピング + premultiply バイリニア補間)。**押しっぱなしにしている間、rAF ループが時間ベース (約1.5倍/秒) で持続適用**し、ドラッグで適用位置を追従。「効果の方向」で膨張 / 収縮を切替、Alt で一時反転。強さ (= strength) は全ツールで共用・サイズ (= radius) はツール別に記憶。選択範囲限定・編集対象レイヤー複数適用・Undo対応
        *   フィルターペン (`Sparkles`, ショートカット: `F`) — **ツールタブの「フィルター効果」 (このツール専用の設定)** を、ドラッグでなぞった範囲のピクセルに直接焼き込む。適用の強さは全ツールで共用・サイズはツール別に記憶。1ストローク内は開始時の画像を基準に置き換わるため効果が積み重ならない。選択範囲・編集対象レイヤーの影響を受ける。**フィルタータブ (全体フィルター) とは独立**しており、ペン使用中も画像全体には影響しない (詳細は 2.3 参照)
    *   **変形**:
        *   パペットワープ (`Pin`, ショートカット: `T`) — ピンを打ってメッシュ (Delaunay 三角分割) ごと画像を滑らかに変形するポーズ・アングル調整ツール。詳細は「2.4 パペットワープ (`puppet-warp`)」参照
    *   **操作**:
        *   スポイトツール (`Pipette`, ショートカット: `I`)
        *   手のひらツール (`Hand`, ショートカット: `H` または `Space`長押し)
*   **カラーインジケータ**: 前景色/背景色スワップ (`X`), クイックパレット, カラーピッカー

### 2.3 Properties Panel (Right Panel - 3タブ構成)
*   **配置**: 画面右側 (幅: 288px / `w-72`)
*   **タブ 1: ツール設定 (Tools)**:
    *   ブラシ/消しゴム/図形/レタッチ/フィルターペンのサイズ・不透明度スライダー & プレビュー円 (フィルターペン選択時は「適用の強さ」表示)
        *   **サイズ (1〜500px) はツールごとに独立して記憶され、ツール切替時に復元される** (既定 24px / 未記録のツールは既定に戻る)。localStorage (`jspaint.toolSizes.v1`) で永続化され、再読込後も復元。スライダー・クイックサイズ・`[` / `]` キーのいずれの変更も自動保存。対象はサイズスライダーを持つ 11 ツール (core/toolDefs.ts の `SIZE_TOOLS`)。不透明度 (強さ) は全ツール共用のまま
    *   **フィルターペン: 「フィルター効果」セクション (選択時のみ表示 / `data-fx-scope="pen"`)**:
        *   ガウスぼかし / シャープ / ノイズ (カラー / グレー切替) / 明るさ / コントラスト / 彩度 / 色相回転 (各ON/OFF + スライダー)。**スライダーをドラッグするとスイッチが自動で ON** になる (ノイズの種類ボタンも同様)
        *   **このツール専用の設定** (`filterPenFx`)。フィルタータブとは独立しており、ON にしても画像全体には影響しない (なぞった範囲にのみ焼き込まれる)
        *   UI はフィルタータブと同一構造 (data-fx-* 属性) を共通実装 (`filtersPanel.ts` のスコープ機構) で bind / sync する (二重実装なし)
    *   膨張ブラシ: 「効果の方向」セグメント (**膨張 / 収縮**、`Alt` = 一時的に反転)
    *   クイックサイズボタン (4px, 16px, 32px, 64px)
    *   図形ツール: 「図形の内側を塗りつぶす (fillShape)」チェックボックス
    *   べた塗りツール: 許容度スライダー (Tolerance: 0〜100)
    *   Magic Wand: 類似色許容度スライダー (Tolerance: 0〜100)
    *   **選択合成モード (New / Add / Subtract)**:
        *   **新規選択**: 既存選択範囲をクリアして新領域を設定
        *   **+ 範囲追加**: 既存選択範囲に新しい領域を合体 (Union / Shiftキー)
        *   **- 範囲除外**: 既存選択範囲から新しい領域を型抜き (Difference / Altキー)
    *   **選択範囲操作**:
        *   塗りつぶし (`Alt+Delete`): 選択範囲を描画色+不透明度で塗りつぶし (ペイントレイヤー)
        *   選択解除 (`Ctrl+D`)
*   **タブ 2: Inpainting 前処理フィルター (Filters)** — **画像全体への適用専用** (`FilterEngine`):
    *   ガウスぼかし / **シャープ (0〜100%)** / ノイズ (0〜100% — **カラー / グレー切替、既定はカラー**) / 明るさ / コントラスト / 彩度 / 色相回転 (各ON/OFF + スライダー)。**スライダーをドラッグするとスイッチが自動で ON** になる (ノイズの種類ボタンも同様)
    *   **シャープはアンシャープマスク** (`FilterSettings.applySharpen`): 「元画像 + 強度 × (元画像 − ぼかし参照)」の差分強調。ぼかし参照は強度に比例して 1〜2.5px、100% で amount 2.0 (はっきり効く)。CSS filter に存在しないため自前実装し、プレビュー / ベイク / フィルターペンはシャープ済み canvas をソースとして使う (アルファは不変・半透明は premultiply 計算で色ズレしない)
    *   **フィルターペンの「フィルター効果」とは独立した設定** (ペン使用中に全体プレビューやベイクと干渉することはない)
    *   **適用先は編集対象レイヤー** (アクティブ + Ctrl+クリックで追加した複数レイヤー。ロック中は除外)
    *   **選択範囲限定適用**: 選択範囲がある場合、フィルターはその範囲のみに適用される (プレビュー / エクスポート両方)
    *   **確定 (Bake)**: 現在のフィルター結果 (選択範囲があればその範囲のみ) を**編集対象レイヤー**のピクセルに焼き込み、フィルター設定をリセットする (Undo対応)
    *   **リセット**: フィルター設定を初期化 (画像は無加工に戻る)
*   **タブ 3: レイヤー管理 (Layers)**:
    *   **レイヤーモデル (Photoshop / Affinity Photo ライク)**:
        *   `元画像レイヤー (image)`: 画像読み込みで生成。**通常レイヤーと同様に編集・複製・削除可能**
        *   `描画レイヤー (paint)`: ブラシ等の描画要素。**Inpainting マスクはこの種別 (+選択範囲) からのみ生成**
        *   起動時 / 画像読み込み時は **元画像レイヤー 1 枚のみ**で開始する (描画レイヤーはユーザーが追加)
    *   **レイヤー操作**:
        *   追加 (`+`) / 複製 / 削除 (最低 1 枚は残す)
        *   **ロック切替** (各行の錠前アイコン): ロック中は描画・フィルター・編集対象から除外 (表示は通常どおり)
        *   表示 / 非表示 (目のアイコン)
        *   **編集対象** (Ctrl+クリックで追加・解除): 描画・レタッチ・フィルター・選択範囲操作の適用先
        *   **Inpainting マスクレイヤーのドット網掛表示**: マスク指定レイヤーはキャンバス上で
            SD WebUI Forge の Inpaint マスク (high contrast) と同じ **白黒チェッカー (10px) × 50% 不透明度**の
            ドット網掛で表示され、**レイヤーサムネイルも同じドット網掛に統一**される (`rendering/maskDisplay.ts`)。
            どんな色・不透明度で描いても表示はドットに統一され、
            レイヤーの実データ (色・アルファ) やエクスポートされるマスク画像には影響しない (表示のみの変換)。
            マスク指定の付け替えは即時に表示へ反映される (サムネイルはレイヤー操作・Undo 等の再生成タイミングで更新)

### 2.4 Workspace & 選択範囲 Marching Ants 仕様
*   **輪郭エッジ追跡 (Contour Edge Tracing)**:
    *   白黒二値マスクCanvasから境界セグメントを検出し、閉ループ群を抽出。
    *   ポリゴン選択で囲んだ領域や、矩形選択から除外した後の複雑な領域（L字型・穴あき型）であっても、**最終的に選択されている領域の外郭境界のみが動的な点線（Marching Ants: 白黒二重破線アニメーション）** としてレンダリングされる。
*   **多角形ポリゴン選択 (`select-polygon`)**:
    *   クリックごとに頂点を追加し、ダブルクリックまたは始点（緑色ドット）クリック、または Enter キーで閉じる。
    *   ダブルクリック時は自動的に始点と結ばれ、即座に動的点線枠へと移行する。
    *   **ドラッグ中は投げ縄のように動作**: 押下中のドラッグで連続頂点を自動収集する (クリックとフリーハンドのハイブリッド)。
*   **選択ペン (`mask-pen`)**:
    *   ドラッグで白黒マスクCanvasに直接ストロークを描き、ストローク確定ごとに境界を再抽出して動的点線に反映する。
    *   選択合成モードに連動 (新規=クリア後に描画 / ＋追加 / −除外=描いた部分をマスクから削除)。
*   **フィルターの選択範囲限定適用 + 確定**:
    *   フィルターON中、選択範囲がある場合は範囲内のみプレビュー適用される。
    *   「確定」でフィルター結果を選択範囲 (または全面) に焼き込み (ベイク)、フィルター設定をリセットする。

### 2.4.1 パペットワープ (`puppet-warp`)
人物のポーズ変更や、立っている人物を見上げるようなローアングル表現のためのメッシュ自由変形ツール。

*   **メッシュ生成 (セッション開始時)**:
    *   編集対象レイヤーを合成した画像の**不透明領域 × 選択範囲 (あれば)** を変形対象とする。
    *   対象領域の外接矩形の四隅 + 「メッシュ間隔」(16〜64px、既定 32px) 刻みのグリッド頂点 + 領域輪郭のサンプル点を、**自前実装の Bowyer-Watson 法 Delaunay 三角分割**でメッシュ化 (外部依存ゼロ)。
    *   メッシュ間隔スライダーを変更するとメッシュを再生成 (ピンと変形はリセット)。
*   **ピン (制御点) 操作**:
    *   **クリック** = ピン追加 (押したままドラッグで即調整可)
    *   **Alt+クリック** = 固定ピン追加 (青表示。ドラッグ移動不可)
    *   **ピンをドラッグ** = MLS (Moving Least Squares) rigid 変形でメッシュ全体を滑らかに変形、リアルタイムプレビュー
    *   **ピンをダブルクリック** = ピン削除
    *   未移動のピンは自動的にアンカー (固定点) として働く
    *   **変形済みの状態でピンを打った場合も「見た目の位置」に打てる**: クリック位置を現在の変形で初期空間へ逆変換 (`inverseDeformPoint`: 変形後三角形の重心座標を初期三角形へ適用) して `original` を求めるため、既存変形と矛盾せず、ピン追加だけでは画像が動かない
*   **プレビューと確定**:
    *   セッション中はレイヤーの実ピクセルを変更せず、変形結果をレイヤーの代わりに表示 (メッシュ線・ピンをオーバーレイ)。
    *   **Enter / 確定ボタン** = Undo スナップショットを積んでレイヤーに焼き込み (選択範囲があれば範囲内のみ)。ツール切替時も自動確定。
    *   **Esc / 取消ボタン** = 変形を破棄して元に戻す。
    *   変形ピクセルが無い状態で確定しても Undo エントリは作らない。
*   **パフォーマンス (プレビューの高速化)**:
    *   ドラッグ中のプレビュー更新は `requestAnimationFrame` で **1 フレームに 1 回へ間引き**、転写の補間品質を一時的に `low` へ下げて軽量化する。
    *   **ピンを離した時点 / 確定時には `high` 品質で仕上げ直す**ため、確定される画質は常に高品質 (低品質はドラッグ中のプレビュー表示のみ)。
    *   三角形ごとの転写は**変形先の外接矩形に対応するソース領域に限定**し、フルサイズ `drawImage` のオーバードローを回避する。
    *   ピンが 1 つも移動していない (恒等変形) うちはメッシュ転写自体をスキップし、ピン追加・削除・メッシュ再生成時の負荷を抑える。
*   **適用対象**: 編集対象レイヤーすべて (膨張ブラシ等と同一のルール)。選択範囲がある場合はその範囲内のみ変形。


### 2.5 Export Modal (Inpainting 連携出力)
*   **合成画像 (Composite Image)**: 背景画像 + 全ペイントレイヤー + 適用フィルターを合成出力
*   **マスク画像 (Inpainting Mask)**: 背景黒 (`#000000`)、ペイント描画要素および合成選択範囲を白 (`#ffffff`) で二値化出力
*   **親アプリ連携**: `postMessage({ type: 'JSPAINT_EXPORT', compositeImage, maskImage })` 送信

### 2.6 画像入出力とホストモード (standalone / embed)

#### 2.6.1 可変ドキュメントサイズ
*   ドキュメント (ステージ) は **640×640 固定ではなく可変**。実寸は `doc.width` / `doc.height` で管理し、
    ヘッダー・ワークスペースのメタ表示・レイヤーパネルに反映される。
*   ドキュメント差し替え (開く / ドロップ / Ctrl+Shift+V) の際に**ドキュメントサイズは読み込み画像の実寸に追従**する。
*   ドキュメント差し替え時は「新しいドキュメントの準備」として、**選択範囲・Undo/Redo・フィルター設定をリセット**する
    (異なるサイズのスナップショット混在を防ぐため)。レイヤーは元画像 1 枚のみに戻る。
*   **「キャンセル」ボタン**: 読み込み直後の初期状態 (レイヤー構成・ピクセル) へ復元し、選択・履歴・フィルターをリセットする。

#### 2.6.2 画像の読み込み
| 経路 | 操作 | 動作 |
|---|---|---|
| ファイルを開く | ヘッダー「開く」ボタン (standalone のみ) | **新規ドキュメントとして読み込み** (元画像レイヤー 1 枚・サイズ追従・名前 = ファイル名) |
| ドラッグ & ドロップ | 画像ファイルをワークスペースへドロップ (オーバーレイ表示あり) | 同上 |
| `Ctrl+V` | クリップボードの画像 (`image/*`) | **新規レイヤーとして現在のドキュメントに追加** (中央配置・ドキュメント名は変更しない) |
| `Ctrl+Shift+V` | クリップボードの画像 | **新規ドキュメントとして読み込み** (開くと同じ) |
| 「クリップボードから新規作成」ボタン | ヘッダーのペーストボタン | **新規レイヤーとして追加** (Ctrl+V の外部画像と同じ) |

*   内部クリップボードに選択範囲のコピー / 切り取りがある場合、`Ctrl+V` はそれを優先して新規レイヤーに貼り付ける (2.6.4)。
*   ドキュメント差し替え時は進行中の操作 (多角形選択 / パペットワープセッション) を自動取消してから適用する。
*   元画像レイヤーは編集可能。**Inpainting マスクには含まれない** (マスクは描画レイヤー + 選択範囲から生成)。

#### 2.6.3 画像の出力 (2経路)
| 経路 | 操作 | 内容 |
|---|---|---|
| 保存 | ヘッダー「保存」ボタン / `Ctrl+S` (standalone のみ) | 合成画像 (全可視レイヤー) を PNG ダウンロード |
| クリップボードコピー | ヘッダー「コピー」ボタン / `Ctrl+Shift+C` (両モード) | 合成画像を `image/png` としてクリップボードへ書き込み (`navigator.clipboard`) |

*   非対応環境 (セキュアコンテキストでない等) では toast で案内する。

#### 2.6.4 レイヤー指向のコピーペースト (内部クリップボード)
*   **`Ctrl+C` (コピー)**: 編集対象レイヤーの合成 × 選択範囲 (選択なし = 編集対象レイヤー全体) を
    内部クリップボードへ保存 (不透明部分の外接矩形で切り抜き、元の位置を記憶)
*   **`Ctrl+X` (切り取り)**: コピー + 編集対象レイヤーから該当範囲を消去 (Undo対応)
*   **`Ctrl+V` (貼り付け)**: 内部クリップボードの内容を**元の位置で新規レイヤー**として貼り付け
    (内部クリップボードがなければ外部画像を新規レイヤーに追加 — 2.6.2)
*   貼り付けたレイヤーはアクティブ + 編集対象になり、そのまま編集できる

#### 2.6.4 ホストモード (standalone / embed)
*   **判定** (`ui/hostMode.ts`):
    1.  URL パラメータ `?mode=embed` / `?mode=standalone` で明示指定 (優先)
    2.  未指定時: iframe 内 (`window.parent !== window`) なら **embed**、それ以外は **standalone**
*   **UI 出し分け**: `<html data-host-mode="...">` を設定し、CSS で
    `html[data-host-mode="embed"] [data-standalone-only] { display: none }` により **standalone 専用 UI を非表示**。
    *   **standalone 専用**: 「開く」「保存」ボタン (親アプリから渡される画像が前提の embed では不要のため)
    *   **両モード共通**: クリップボードコピー / Ctrl+V ペースト / ドラッグ&ドロップ / ズーム・選択等の編集機能
*   **embed 時の Ctrl+S**: 保存は行わず「完了 (Ctrl+Enter) で親アプリへ返す」旨を toast で案内する。
*   呼び出され方の例: Stable Diffusion Web UI から iframe + `?mode=embed` で読み込む場合、
    ファイル I/O は親アプリに任せ、エディタは画像編集と postMessage 返却に専念する。

## 3. ショートカット一覧

| キー | 動作 |
|---|---|
| `B` / `E` / `G` | ブラシ / 消しゴム / 塗りつぶし |
| `L` / `U` / `O` | 直線 / 矩形 / 円 |
| `M` / `Q` / `P` / `W` / `K` | 矩形選択 / 投げ縄 / 多角形 / 魔法の杖 / 選択ペン |
| `T` | パペットワープ (ピン追加=クリック / 固定ピン=Alt+クリック / 削除=ダブルクリック) |
| `S` / `V` / `D` / `J` / `F` | 指先 / 膨張 / 覆い焼き / 焼き込み / フィルターペン |
| `I` / `H` | スポイト / 手のひら (`Space` 長押しでもパン) |
| `X` | 描画色と背景色を入れ替え |
| `[` / `]` | ブラシサイズを段階的に変更 |
| `Shift` / `Alt` (ドラッグ中) | 選択範囲の追加 / 除外 |
| `Ctrl+Z` / `Ctrl+Y` | Undo / Redo |
| `Ctrl+A` | すべて選択 |
| `Ctrl+D` | 選択解除 |
| `Ctrl+C` / `Ctrl+X` | 選択範囲 (選択なし = 編集対象レイヤー全体) をコピー / 切り取り |
| `Ctrl+V` | 内部クリップボード or OS クリップボードの画像を新規レイヤーとして貼り付け |
| `Ctrl+Shift+V` | OS クリップボードの画像で新規ドキュメントを読み込み |
| `Ctrl+S` | 合成画像を PNG 保存 (standalone モードのみ) |
| `Ctrl+Shift+C` | 合成画像をクリップボードへコピー |
| `Alt+Delete` (Alt+Backspace) | 選択範囲を描画色で塗りつぶし |
| `Delete` | 選択範囲内を消去 |
| `0` / `1` | ズーム100% / 画面フィット |
| `Ctrl+Enter` | Inpaintingエクスポート(モーダル)を開く |
| `Enter` (パペットワープ中) | 変形を確定してレイヤーに焼き込み |
| `Esc` (パペットワープ中) | 変形を取消 |
| `Esc` | 多角形選択の取消 / モーダルを閉じる |
| `Enter` (多角形中) | 多角形選択を確定 |
